Let HYPERFIDE browse, click, fill out forms, and check web pages for you. Control the in-app browser or run headless browsers on your local and remote machines connected to HYPERFIDE.

Headless sessions include live inline previews in the chat, so you can watch HYPERFIDE work and expand the preview for a closer look. In-app browser sessions stay visible in HYPERFIDE's browser panel.

Enable Browser Automation in plugin settings, then ask HYPERFIDE to open a page, test a flow, or verify a change.
