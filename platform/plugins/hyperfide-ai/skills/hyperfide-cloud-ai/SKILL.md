# Hyperfide cloud AI

Hyperfide cloud is the `Hyperfide` AI service from the `hyperfide-ai` plugin. It writes thread
titles (branch names follow the title) and commit messages and transcribes
voice input for a signed-in Hyperfide account, within a daily spend limit per account.
