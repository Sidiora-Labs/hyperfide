# Fleet prerequisites in the native release inventory

The four canonical cases re-run the existing complete live prerequisite oracle against an explicit private target and evidence index. The oracle opens an independently verified PostgreSQL read-only transaction, validates signed provider/worker captures, checks contract/source pins, and reconciles the complete installation, model, worker and supervisor chain. Prior component receipts and stored PASS flags do not satisfy it.

SCM-026 adds the real 23-case contract parser/interface-index execution, then requires the live installation and bounded interface-selection observations. SCM-027 selects installation and provider/worker isolation observations. SCM-028 selects actual model decisions, co-location, replanning/refusals and their worker effects. SCM-029 selects supervisor loss, stale generations, uncertain effects, worker cancellation and independent qualification. Every case additionally requires the full live chain, even when its selected assertions focus on one part.

Set `HF_FLEET_QUALIFICATION_TARGET` and `HF_FLEET_QUALIFICATION_EVIDENCE` to their protected JSON files and supply the database credential named by that target. Run `prerequisites.py --case SCM-026` (or 027–029). Missing actual evidence produces exit77. Use `prerequisite_manifest.py` with the shared native implementation capture to prepare each canonical manifest; the release campaign rechecks registered source roots against that capture. The Git source identities inside historical fleet evidence retain their original meaning and do not replace the release's native source identity.
