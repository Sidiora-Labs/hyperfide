# Index resource measurements

The JSON files are raw one-run measurements from the v1.6 indexing gate. The
fixture is generated by `tests/scale/gen.py` with seed 15 and two workers. The
binary hash, operating system, effective CPU count, SQLite version, FTS mode,
source bytes, stage times, phase times, peak RSS, database sizes, coverage and
diagnostics are recorded in each file. Host and cache effects can change wall
time; these numbers are observations, not universal latency targets. The
`cg init` output replaces the ephemeral index directory with `<index>`; timing,
resource, coverage and source metadata remain the directly measured values.

Reproduce the small gate and either profile from the repository root:

```sh
make -j1 cg
CG=$PWD/cg bash tests/integration/77_index_resources.sh
python3 scripts/bench-indexing.py --files 20 --lines 700 --seed 15 --workers 2 --cg "$PWD/cg" --output /tmp/v16-small.json >/dev/null
python3 scripts/bench-indexing.py --profile large --seed 15 --workers 2 --cg "$PWD/cg" --output /tmp/v16-large.json >/dev/null
```

The large profile requests 1,000 files and 100,000 lines; the deterministic
generator produced 97,484 lines and 2,485,542 source bytes in this run. It
also indexes a separate Go fixture with 160,000 sibling comment lines and 600
nested blocks. Each normal stage has a 120-second process deadline; each
pathological shape has a 30-second deadline. A timeout fails the run. The
default integration gate uses 20 generated files and 20,000 wide comment lines.
